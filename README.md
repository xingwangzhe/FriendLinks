# 博客宇宙

[![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new/clone?repository-url=https://github.com/xingwangzhe/FriendLinks)

> 探索浩瀚的个人博客宇宙，寻找彼此之间的联系。每个节点是一个以文字文章为核心的个人博客，每条连线是一段友链关系。

**法律合规说明：** 网站所有者和投稿者必须确保其发布内容及网站运营遵守中华人民共和国以及适用情况下的美利坚合众国法律法规。

**请确保：** 你的站点使用 `https` 并可以在中国大陆访问。

## 站点定位

本站只收录个人文章博客，不接受博客聚合、导航站或内容平台。聚合与导航的发现功能与本站重复，内容平台则不属于个人博客。

- **收录**：个人、笔名作者或小型非机构创作团队运营的文字博客；必须有公开文章索引、至少一篇原创正文和独立永久链接。
- **允许混合**：博客可以同时包含技术、生活、随笔、日记、教程、摄影、视频或播客等次要内容，但文章写作必须是站点的主要用途。
- **不收录**：纯作品集、纯照片/图库、纯视频/播客、纯个人主页、link-in-bio、在线简历，以及以产品、服务、社区或聚合为核心功能的站点。

## 快速添加你的博客

确认站点符合上述定位后，在 `links/{你的域名}.yml` 中填写：

```yaml
site:
  name: 我的博客
  description: 分享编程和技术相关的文章
  url: https://example.com
  # aliases: [https://old.example.com/] # 可选，仅填写已确认的同义入口
  color: "#ff6600" # 可选，自定义节点颜色（16 进制）
  links: /links # 可选，友链页面路由（默认 /links）
  friends:
    - name: 编程小站
      url: https://codehub.example.com
```

提交 PR 即可。

> **友链页面路由**常见值：`/links`、`/link`、`/friends`、`/friend`、`/links.html` 等。

## 相似站点与重复记录策略

一个逻辑站点只保留一份正式 YAML：`site.url` 是规范主入口，可选的 `site.aliases` 声明已确认的旧域名、镜像或其他入口。不同地址指向同一站点时，将地址记录为别名并合并重复文件；同作者运营的不同博客、同域名下的独立栏目仍分别保留。

```yaml
site:
  name: Example Blog
  description: 记录技术、生活与阅读的个人博客
  url: https://example.com/
  aliases:
    - https://old.example.com/
  links: /links
  friends: [] # 格式示例；迁移时保留现有友链并集
```

| 情况                                                            | 处理策略                                                                        |
| --------------------------------------------------------------- | ------------------------------------------------------------------------------- |
| 主地址规范化后相同，含 HTTP/HTTPS、末尾斜杠和国际化域名表示差异 | 自动解析为同一身份；整理为一份 YAML                                             |
| `www` 变体、相似域名、同名站点、托管镜像                        | 只筛为候选，使用 `crwl` 检查跳转、canonical、内容与发布入口；确认后声明 aliases |
| 同一作者、品牌或注册域下的不同站点；独立语言站或栏目            | 保留独立身份，不因归属相同直接合并                                              |
| 验证页、停放页、访问失败或证据不足                              | 不新增同义关系，保存待复核原因                                                  |

维护流程为“全量统计候选 → `crwl` 逐项复核 → 确认规范入口 → 合并 aliases 与友链并集 → 合并 YAML → 校验关系保留”。规范主记录优先提供元数据；合并来源和证据写入注释与报告。重复文件按稳定路径顺序确定主记录，缺失的可选字段从其他记录补齐。历史友链并集不代表逐条重新验证了当前有效性。

加载器也会合并重复记录，先解析完整身份再进行开发采样；图、统计、六度工具和 `/all.json` 共用同一逻辑集合及拓扑。根入口覆盖同 host 路径，栏目按路径段边界和最长匹配归属；带查询参数的入口精确匹配。不同 hostname 必须显式声明别名，非默认端口保持区分。

`bun run validate` 会检查格式、别名冲突和迁移环，错误时非零退出。整理时比较合并前后的逻辑记录与纯拓扑，必要时运行轻量测试；未经明确授权不运行 `bun run build`，不为去重重新启用 `outdated/` 的审核脚本。单纯合并已在加载时折叠的 YAML 不会再次减少图节点；性能改善应区分文件读取、拓扑规模与实际构建耗时。

完整边界、操作步骤与统计字段见 [站点身份与重复站点策略](docs/SITE-IDENTITY.md)。2026-10-02 的处理记录见 [相似地址复核报告](reports/alias-review-2026-10-02/README.md)及 [重复 YAML 合并报告](reports/yaml-consolidation-2026-10-02/README.md)。

## ✨ 3D 渲染特性

### 节点系统

- **实例化球形替身** — `SpriteNodeMaterial` + TSL，每节点两个三角形，保留圆形轮廓和径向明暗。
- **紧凑实例属性** — 中心与半径使用 Float32，颜色使用 normalized RGBA8；CPU 矩阵保留给聚焦和拾取。
- **统一节点半径** — 默认 40 世界单位，聚焦放大 1.5 倍；24 色调色板区分站点。
- **兼容两种后端** — WebGPU 优先，Three.js 自动回退 WebGL；两条路径均完成全量图渲染检查。

### 连线与路径

- **自适应贝塞尔曲线** — 每条关系按长度保留 16–32 段，indexed geometry 共享相邻端点，RGBA8 保留颜色渐变。
- **按需高亮** — 光晕和核心使用两个实例批次、无光照材质和无端盖圆柱；只处理当前节点的关联边。
- **背景线默认隐藏** — 显示时才生成完整曲线缓冲，隐藏后释放，重新开启时重建。
- **BFS 最短路径** — 浏览器端 TypeScript BFS 与金色路径管道；步进只更新前后两个节点的颜色。

### 绘制预算

- **空闲停绘** — 无变化时不申请 RAF；隐藏页面暂停，解锁鼠标后暂停飞行。
- **低带宽输出** — 关闭 MSAA、使用不透明画布和 8bit 输出缓冲，默认 DPR 上限 1；不锁帧，静止停绘。
- **有界标签** — 查询附近空间格并保留最近预算；每批最多生成四个文字纹理，等待下一批时不重复绘图。

球形替身在极近距离下采用平面深度近似，8bit 输出会量化暗色渐变；这是默认性能取向的画质取舍。实测和复现步骤见 [前端性能说明](docs/PERFORMANCE.md)。

## 🎮 交互方式

| 操作              | 效果                                 |
| ----------------- | ------------------------------------ |
| 左键点击节点      | 在新标签页打开网站                   |
| 中键点击节点      | 在新标签页打开网站，保留当前视角     |
| 右键点击节点      | 聚焦该节点（相机拉近、光晕连线）     |
| 拖拽              | 旋转 3D 视角                         |
| 滚轮              | 缩放                                 |
| 顶部搜索框        | Orama 搜索（域名分词与中文双字分词） |
| URL `?local=域名` | 自动聚焦指定节点                     |

### 控制面板（顶部按钮）

| 参数       | 范围              | 默认值   | 说明                                   |
| ---------- | ----------------- | -------- | -------------------------------------- |
| 连线透明度 | 0~1               | 0        | 基础线网透明度（加法混合发光不受影响） |
| 飞船速度   | 自动基准 35%~250% | 自动基准 | 按节点数量与分布体积密度推算，可微调   |
| 节点标签   | 开/关             | 开       | 3D 文字标签显隐                        |

所有参数自动持久化到 `localStorage`，刷新页面保持上次设置。

飞船速度以 `cbrt(包围盒体积 / 有效节点数) × 0.65` 推算，并限制在 120~12000 单位/秒。速度滑块的最小值、最大值和当前位置随每次图加载自动更新；修改后保存相对自动基准的比例，「恢复自动」可回到当前图的基准速度。

### 飞船模式（🚀 按钮）

| 操作   | 功能                                 |
| ------ | ------------------------------------ |
| 鼠标   | 直接控制偏航和俯仰，准星固定在中心   |
| WASD   | 前后左右平移                         |
| R / F  | 上升 / 下降                          |
| Q / E  | 横滚                                 |
| Shift  | 加速 3×                              |
| Space  | 自动前进切换                         |

飞船模式不显示大面板，只在屏幕底部显示半透明快捷提示。提示不接收指针事件，`X` 用高亮文字提示退出，避免遮挡穿越视野。飞行中鼠标键只负责锁定和转向，不打开或聚焦节点。

## 🚀 性能设计

| 技术               | 说明                                                                       |
| ------------------ | -------------------------------------------------------------------------- |
| **节点实例化**     | 每节点两个三角形的 TSL Sprite；中心/半径与 RGBA8 紧凑属性                  |
| **高亮连线实例化** | 悬停/聚焦时按需创建光晕和核心两个实例批次，不再预建 32,000 个 Mesh         |
| **按需渲染**       | 交互、相机动画、缩放和设置变化唤醒；阻尼停止后不申请下一帧，隐藏标签页暂停 |
| **延迟连线缓冲**   | 默认零背景缓冲；显示时共享端点并量化颜色，隐藏后立即释放                   |
| **空间拾取**       | BVH 近处优先剪枝，节点使用解析球体拾取，静止射线复用结果                   |
| **标签预算**       | 只保留视锥内的近处标签，每批最多创建 4 个，限制纹理数量                    |
| **画质档位**       | 默认节能：DPR 上限 1、不锁帧；均衡/清晰与帧率上限可独立切换并持久化        |

控制面板的「帧率上限」默认选择「无限制」，60 Hz 屏幕通常约 60 FPS，高刷新率设备可超过 60 FPS；也可手动选择跟随画质限帧。该选择会保存，切换画质仍保留，静止及后台均停绘。画质档位、复测步骤、实测结果与验证范围见 [前端性能说明](docs/PERFORMANCE.md)。

## 数据格式

### 图数据端点

| 端点                | 格式                  | 说明                                         |
| ------------------- | --------------------- | -------------------------------------------- |
| `/graph-core.bin`   | msgpack + zstd 二进制 | 核心图数据（节点、边、邻接表），首屏优先加载 |
| `/graph-bezier.bin` | msgpack + zstd 二进制 | 贝塞尔曲线数据，核心图加载后异步获取         |
| `/all.json`         | JSON                  | 完整站点数据（外部使用）                     |

### 数据流

```
links/**/*.yml（排除保留目录 links/unverified/）
               →  YAML Schema 校验 → build-graph.ts (力导布局+贝塞尔预计算)
               →  graph-core.bin.ts (msgpack+zstd) →  /graph-core.bin
               →  graph-bezier.bin.ts (msgpack+zstd) →  /graph-bezier.bin
               →  客户端 fetch → zstd 解压 → msgpackr 解码 → Three.js 3D 渲染
```

## 本地开发

项目使用 **Bun** 管理依赖和运行 Astro。开发与预览脚本通过 `bunx --bun astro@latest` 启动；生产构建由 `scripts/build.ts` 调用锁文件安装的 Astro，并输出 Astro、后处理和总耗时，均使用 Bun 运行时。

```bash
# 安装依赖
bun install

# 启动开发服务器
bun run dev

# 预览已有构建产物
bun run preview

# 构建生产版本（耗时较长，代理执行前必须获得用户明确授权）
bun run build

# 轻量检查
bun run lint
bun run check  # Astro 文件与 TypeScript 严格类型检查（TypeScript 6.x）
bun run fmt-check
bun run validate

# 写入格式化结果
bun run fmt
```

### dev 正式站点数量

在 `astro.config.mjs` 顶部调整 `DEV_SAMPLE_SIZE`（默认 `100`），或在启动时用同名环境变量覆盖：

```bash
DEV_SAMPLE_SIZE=100 bun run dev  # 抽样最多 100 个正式站点
DEV_SAMPLE_SIZE=500 bun run dev  # 临时改为最多 500 个
DEV_SAMPLE_SIZE=0 bun run dev    # 加载全部正式站点
```

配置控制正式站点抽样数量，不是最终星球总数：友链目标仍可能生成额外星球。`0` 表示不限量；大于可用站点数时加载全部。只接受非负安全整数，非法值会在启动时报错。环境变量优先于配置常量，修改后重启开发服务器。生产构建始终加载全量正式数据。

全量 dev 仍使用 dev 力导模拟参数，但可能明显增加加载和布局开销。详细说明见 [开发配置](docs/DEV.md)。

### 运行版本与 CI

开发与预览的 `@latest` 会跟随 Astro 的最新发布版本；生产构建使用本地已安装版本，避免构建时解析远程最新版造成不确定性。构建开头会打印 Bun、Astro 版本。

GitHub Actions 使用 `oven-sh/setup-bun@v2` 安装最新版 Bun，然后执行 `bun install --frozen-lockfile` 和 `bun run build`，复用经过内容校验的构建缓存，不再单独安装 Node.js。源码中的 `node:fs`、`node:path` 等导入使用 Bun 的 Node.js 兼容 API。构建缓存、强制重算与跨仓库基准见 [构建性能报告](docs/BUILD-PERFORMANCE.md)。

开发类型依赖包含 `@types/bun` 1.4.2 和 `@types/node` 26.6.4；保留 Node 类型用于兼容 API 与依赖声明。代码检查使用 oxlint 1.86.0 和 TypeScript，格式化使用 oxfmt 0.71.0。上述版本为 2026-10-02 的依赖更新记录，不代表今后的固定版本。

### 站点准入与数据维护

正式数据仅收录个人、笔名作者或小型非机构创作团队运营的文字博客。审核按公开可访问性、原创文章、文字内容占比、运营主体及主要用途判断，不能仅凭 RSS、框架或站名认定。

- `include`：合格的个人文章博客放入普通 `links/` 分类。
- `unverified`：暂时无法确认是否为个人文章博客的候选放入 `links/unverified/`，默认不进入构建、端点和图分析。
- `exclude`：纯作品集、纯照片、纯个人主页、博客聚合、导航站、社区、平台及其他不符合定位的站点不创建占位节点。

完整准入规则见 [AGENTS.md](AGENTS.md)，候选注释格式见 [候选目录说明](links/unverified/README.md)。合格博客没有公开友链页时可以使用 `friends: []`。

## 前端控件与面板

界面统一使用 Tailwind CSS v4 与 daisyUI 免费组件。按钮、输入框、滑块、开关、加载状态和统计卡片均采用原生 HTML，可叠加 Tailwind 工具类。

统计、关于、控制、邻居和路径查找使用原生 `<dialog>` 非模态面板，不依赖第三方窗口库。宽面板居中偏上，邻居和控制面板靠右，路径查找停靠底部；移动端统一为底部 sheet。面板可用关闭按钮或 Escape 关闭，关闭后焦点返回入口按钮，打开时宇宙仍可继续交互。

飞船模式只使用底部 HUD：半透明淡文字、`pointer-events: none`、不获取焦点；`X` 使用高亮提示退出。

开发验证使用 `bun run dev` 的抽样数据，运行 `bun run lint`、`bun test`、`bun run verify:controls` 与改动文件格式检查；浏览器验收覆盖中键悬停提示、面板开关、鼠标只转向、WASD/RF 位移、Shift 加速、Q/E 横滚、X 退出水平恢复、速度滑块和静止停绘。开发模式会清理本项目旧 Service Worker 缓存，避免加载过期控件代码。不得以生产构建替代 dev 检查。

界面固定使用 daisyUI 暗色主题，与宇宙背景一致，不提供亮色模式或主题切换入口；系统浅色偏好及历史 `colorTheme` 本地设置均不影响页面。
