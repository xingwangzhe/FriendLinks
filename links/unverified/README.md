# 待验证候选

此目录只存放暂时无法确认是否符合“博客宇宙”准入标准的候选站点。这里的 YAML **不会进入正式图数据、构建产物、统计或默认分析流程**。

适合进入本目录的情况包括：站点暂时无法访问、抓取被阻止、作者归属或原创性不明、站点用途混合、内容完全登录或付费可见，以及暂时无法区分博客、作品集或博客聚合站。已经明确不合格的站点不要在此占位。

## 文件格式

候选沿用正式站点的 YAML Schema，文件名仍为 URL 中的域名。不要增加 `review`、`type`、`status` 等 Schema 外字段；审核信息必须使用文件顶部的 YAML 注释记录。

```yaml
# 审核状态: unverified
# 原因码: unverifiable
# 证据: https://example.com/about
# 证据: https://example.com/blog
# 检查日期: 2026-08-19
# 备注: 首页可访问，但暂时无法确认文章是否为原创内容。

site:
  name: 示例候选
  description: 待验证的站点描述
  url: https://example.com
  links: /links
  friends: []
```

可以写多个“原因码”和“证据”注释。原因码必须使用 `AGENTS.md` 准入章节中的统一列表，检查日期使用 `YYYY-MM-DD`。

`friends: []` 仅表示暂未发现公开友链，不是准入证明。已经确认符合标准的博客可以没有友链；已经明确不是博客或博客聚合站的网站，不能靠空数组保留节点。

## 验证与复核

只校验本目录候选的 YAML 结构：

```bash
bun run validate links/unverified
```

只生成本目录候选的审核报告：

```bash
bun run audit --dir links/unverified
```

复核时按以下顺序执行：

1. 检查 URL 安全性、公开可访问性、跳转结果和规范域名。
2. 优先判断是否为 `blog-aggregator`。
3. 若不是聚合型，确认是否有文章索引及至少一篇公开、原创、有实质正文和独立永久链接的内容。
4. 确认运营主体和主要目的没有触发硬排除规则。
5. 更新顶部的原因、证据、检查日期和备注，再决定晋升或排除。

## 晋升与排除

- 确认是 `blog`：将 YAML 移动到普通 `links/` 分类目录。
- 确认是 `blog-aggregator`：将 YAML 移动到 `links/aggregators/`。
- 确认不符合标准：删除候选文件，或将调查结果移交到单独的审核报告；不要在正式目录或本目录留下占位节点。
- 仍缺少证据：继续保留在本目录，并更新检查日期与复核备注。

晋升前应移除“审核状态: unverified”及仅与待验证状态有关的注释，同时保留仍有长期价值的数据来源说明。
