# 关于 - 独立博客传送门
![](https://webteleporter.top/img/main.png)
从最初的 Jekyll, 到 Gatsby, 再到最终的 NextJS.  
子站点从 Hexo 变为 Remix, 从 Vue 到 Docusaurus.  
从 ES5 到 ES15, 从 jQuery 到 React, 从 React 0.11 到 React 19.  
从 CSR 到 SSR, 再到 Server Component.  
样式从最初的 Bootstrap 到 MUI 和 Tailwind, 到完全自己定制.  
评论框从有言, 多说, 到 Disqus.  
Repo 从 Oschina 到 Gitee, 到 Coding, 再到 Github.  
我时刻在想, 没有任何收益, 为什么要这么折腾?
—— 《2025 博客第十年展望 - 再见我的过去》
## 动机
开放, 自由, 独立, 公平, 互联, 共享, 尊重, 理性, 包容, 合作, 信任, 感恩.
"传送门" 是一个为独特个体而生的博客聚合站点，我们相信，每个人的思考和表达方式都有其独特的魅力。在这里，我们不关心流行趋势，不追逐热点，只希望发现那些有趣的灵魂，分享那些不被算法定义的真实声音。
十年前，我开始写博客，不是为了炫耀知识，而是为了记录自己的所思所想，表达自己的世界观。在这个过程中，我遇见了许多特别的人，他们的故事、他们的独特表达，远比任何技术进步更让我着迷。
## 传送门的愿景
  1. **记录真实自我** —— 每一个独立的声音都值得被听见，每一种独特的表达都应被珍惜。
  2. **尊重个性表达** —— 让思想自由生长，而不是被算法左右，不因流行趋势而湮灭。
  3. **连接思想孤岛** —— 让志同道合的人相遇，让不同视角的人碰撞，让孤立的个体找到共鸣。


在短视频时代，独立博客逐渐式微，原因在于信息消费方式的转变。短视频以其快速、直观的特点吸引了大量用户，而独立博客的深度内容和文字表达却显得相对“慢节奏”。人们习惯了碎片化的信息获取，逐渐失去了耐心去阅读长篇文字或深度思考的内容。
然而，独立博客的价值并未因此消失。它们承载着创作者的思想深度和个性表达，是短视频无法替代的精神家园。在这个快节奏的时代，独立博客更像是一片净土，为那些愿意停下来思考的人提供了一个安静的角落。
"传送门" 的诞生，正是为了守护这些独立博客的价值。我们希望通过聚合这些独特的声音，让它们不被时代的洪流淹没，让真正有意义的内容得以传承和传播。
