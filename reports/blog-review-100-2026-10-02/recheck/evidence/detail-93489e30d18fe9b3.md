# 小狼毫Weasel&小企鹅Fcitx5-Android Rime输入法折腾
·(已编辑)·教程 / Fcitx5, Weasel, 输入法· 阅读0简体中文
这篇文章上次修改于，可能部分内容已经不适用，如有疑问可询问作者。
关键洞察
作者因魅族自带搜狗输入法在 Chrome 中频繁出现表单无法输入、重复输入，且不能联动密码管理器，转而折腾输入法方案。最终采用 Windows：小狼毫+白霜拼音+中文维基词库，Android：小企鹅 Fcitx5-Android+Rime+白霜拼音+中文维基词库。文章介绍了先下载并配置白霜拼音、添加中文维基词库，再分别在 Android 安装 fxliang fork 版 Fcitx5 与 Rime 插件，通过电脑复制配置到数据目录并重新部署；Windows 则安装 fxliang fork 版小狼毫，将同样配置复制到用户文件夹后部署并选择方案，还可美化界面。剪切板同步使用 VPS 部署 SyncClipboard，Android 由小企鹅内置支持，Windows 安装客户端。整体方案折腾后更贴合个人输入习惯。
##  起因[](https://www.vlo.cc/posts/jc/rime-input-method-configuration#%E8%B5%B7%E5%9B%A0)
主要起因是魅族自带的搜狗输入法，在用Chrome时经常出现一些表单打字打不上、重复输入，且没法与密码管理器联动（目前主用[Monica](https://github.com/JoyinJoester/Monica)，聚合 Bitwarden 与 KeePass，且能用passkey，虽然bug不少），真是忍了好久了！！！  
也试过Gboard，但是总感觉怪怪的，不是很习惯，这几天又搜 输入法推荐、剪切板同步， 看见 小企鹅输入法 （Fcitx5-Android） 尝试下感觉不错，又找到fork版，发现能配置剪切板同步，遂开始折腾。。。
##  最终方案[](https://www.vlo.cc/posts/jc/rime-input-method-configuration#%E6%9C%80%E7%BB%88%E6%96%B9%E6%A1%88)
Windows：小狼毫+白霜拼音+中文维基词库  
Android：小企鹅+Rime+白霜拼音+中文维基词库
##  前置配置-白霜拼音[](https://www.vlo.cc/posts/jc/rime-input-method-configuration#%E5%89%8D%E7%BD%AE%E9%85%8D%E7%BD%AE-%E7%99%BD%E9%9C%9C%E6%8B%BC%E9%9F%B3)
因为Rime的配置在Windows与Android是通用的，这里把这项配置放最前面，等会配置Windows与Android直接CV就行。  

  1. 下载白霜拼音


[ Repository · gaboolic 3.7k rime-frost 白霜拼音：蒹葭苍苍，白露为霜。白霜拼音使用高质量语料，进行分词，重新统计字频、词频，归一化，打造纯净、词频准确、智能的词库。白霜词库是目前rime方案下最好的开源词库，经评测准确性已经不输于商业输入法。在墨奇输入法内置，欢迎使用。 Lua ![gaboolic/rime-frost](https://avatars.githubusercontent.com/u/3831173?v=4) ](https://github.com/gaboolic/rime-frost)
去Releases下载最新的 rime-frost-schemas.zip 或者下载整个仓库，解压到你觉得方便的文件夹📁，方便配置自定义。  
一下示例以📁rime-frost-master 文件夹演示：
![PixPin_2026-06-30_20-16-49.png](https://mio.vlo.cc/mixspace/blog/2026/06/30/ng5aeqyatdnaczbfoe.png)
  1. 新增更多的 自定义词库  
我自己是新增了 中文维基词库 


[ Repository · felixonmars 1.1k fcitx5-pinyin-zhwiki Fcitx 5 Pinyin Dictionary from zh.wikipedia.org Python ![felixonmars/fcitx5-pinyin-zhwiki](https://avatars.githubusercontent.com/u/1006477?v=4) ](https://github.com/felixonmars/fcitx5-pinyin-zhwiki)
下载最新的zhwiki-*.dict.yaml 这是给Rime使用的词库文件，可选 web-slang-*.dict.yaml
可以重命名为zhwiki.dict.yaml 把文件名时间删掉，方便后续更新替换；
把下载的词库文件统一放入📁rime-frost-maste 文件夹。
  
打开 rime_frost.dict.yaml 添加自定义词库
![PixPin_2026-06-30_20-03-16.png](https://mio.vlo.cc/mixspace/blog/2026/06/30/05rw44n4n6589zsyry.png)
在最后这里添加词库，这个应该跟排序有关系，貌似是根据顺序来匹配词库的（不懂捏，有懂得可以评论区说下）  
注意打开词库文件确认 name: zhwiki ，添加其余词库文件最好确认下。
##  Android 小企鹅 Fcitx5 输入法[](https://www.vlo.cc/posts/jc/rime-input-method-configuration#android-%E5%B0%8F%E4%BC%81%E9%B9%85-fcitx5-%E8%BE%93%E5%85%A5%E6%B3%95)
###  Fcitx5-Android与Rime插件 安装与基础配置[](https://www.vlo.cc/posts/jc/rime-input-method-configuration#fcitx5-android%E4%B8%8Erime%E6%8F%92%E4%BB%B6-%E5%AE%89%E8%A3%85%E4%B8%8E%E5%9F%BA%E7%A1%80%E9%85%8D%E7%BD%AE)
[ Repository · fxliang 215 fcitx5-android Fcitx5 input method framework and engines ported to Android, with enhanced features Kotlin ![fxliang/fcitx5-android](https://avatars.githubusercontent.com/u/4023160?v=4) ](https://github.com/fxliang/fcitx5-android)
使用fxliang fork版本，最重要是有剪切板同步，原版也有剪切板同步插件可以用。
  1. 下载fxliang fork的版本并安装


![PixPin_2026-06-30_19-11-13.png](https://mio.vlo.cc/mixspace/blog/2026/06/30/zjz4vazle3y0yxw5kl.png)
下载fx版（包名为：org.fcitx.fcitx5.android.fx，方便与官方版or其他fork版共存，方便体验）以及Rime插件，这个Rime插件是适配fx版的，当然原版也可以用捏。
  1. 添加Rime


![S60630-19170729_org.fcitx.fcitx5.android.fx.png](https://mio.vlo.cc/mixspace/blog/2026/06/30/lj4o5r8vk8gchxl1a9.png)
输入法设置➡️右下角添加中州韵（刚刚安装的Rime插件），然后点右边⚙️进入Rime插件设置，可以点下重新部署，然后打开用户数据目录，这个目录是存放词库、配置文件等目录。
Warning
注意：数据目录在Android/data目录下，因此在手机上操作可能需要点技巧能访问以及往此文件夹复制文件，有电脑最好，贼方便。
###  Rime + 白霜拼音[](https://www.vlo.cc/posts/jc/rime-input-method-configuration#rime-%E7%99%BD%E9%9C%9C%E6%8B%BC%E9%9F%B3)
由于需要访问：Android/data/org.fcitx.fcitx5.android.fx/files/data/rime此我处只讲电脑辅助操作，一些手机文件管理器也能操作，但是不如插电脑（
  1. 手机有线连接电脑  
打开此电脑\MEIZU 22\内部共享存储空间\Android\data\org.fcitx.fcitx5.android.fx\files\data\rime


注意路径改成自己的，当然用电脑了，找这路径就方便多了吧（  
把前置配置提到的📁rime-frost-maste 文件夹 的内容全部复制粘贴到  
此电脑\MEIZU 22\内部共享存储空间\Android\data\org.fcitx.fcitx5.android.fx\files\data\rime
  1. 配置Rime+白霜拼音  
手机打开Fcitx5，输入法设置➡️中州韵⚙️，点击立即重新部署，这种较大的包得稍等一会。  
等重新部署完，进入：方案选择 将多余的取消勾选，选择 白霜拼音 或者选自己需要的。  
找个输入框呼出输入法，选择 白霜拼音，还有一些其余配置，如默认英文标点，联想emoji等。


![S60630-19504734_org.fcitx.fcitx5.android.fx.png](https://mio.vlo.cc/mixspace/blog/2026/06/30/v0e89tgl7k2g2a96mi.png)
这样白霜拼音就成功配置，并且加载了前置配置中提到的的自定义词库，如：中文维基词库；几乎没有比较难的地方，像常见的雾凇拼音、万象拼音、白霜拼音，这些方案大多是很方便配置的，下载、CV。
##  Windows 小狼毫 Weasel 输入法 [](https://www.vlo.cc/posts/jc/rime-input-method-configuration#windows-%E5%B0%8F%E7%8B%BC%E6%AF%AB-weasel-%E8%BE%93%E5%85%A5%E6%B3%95)
###  小狼毫 Weasel 安装与基础配置[](https://www.vlo.cc/posts/jc/rime-input-method-configuration#%E5%B0%8F%E7%8B%BC%E6%AF%AB-weasel-%E5%AE%89%E8%A3%85%E4%B8%8E%E5%9F%BA%E7%A1%80%E9%85%8D%E7%BD%AE)

依旧使用fxliang fork版本。
  1. 下载fxliang fork的版本并安装  
也没什么好说的，根据提示安装就行~  
WIN+Space 切换到小狼毫，


![PixPin_2026-06-30_20-39-12.png](https://mio.vlo.cc/mixspace/blog/2026/06/30/0phwov0tehidlkwrra.png)

###  小狼毫 + 白霜拼音[](https://www.vlo.cc/posts/jc/rime-input-method-configuration#%E5%B0%8F%E7%8B%BC%E6%AF%AB-%E7%99%BD%E9%9C%9C%E6%8B%BC%E9%9F%B3)
  1. 白霜拼音配置  
  
依旧把前置配置提到的 📁rime-frost-maste 文件夹 的内容全部复制粘贴到用户文件夹  
右键托盘重新部署 ，等待部署完成；完成后右键托盘输入法设定 选择白霜拼音 ；或者选自己需要的配置。  
Windows其实配置简单很多，操作也方便。
  2. 小狼毫美化  
  
右键托盘打开用户文件夹 找到weasel.custom.yaml ，这是自定义配置，可以网上找大佬的美化配置或者问AI。

##  剪切板同步[](https://www.vlo.cc/posts/jc/rime-input-method-configuration#%E5%89%AA%E5%88%87%E6%9D%BF%E5%90%8C%E6%AD%A5)
我的方案：VPS部署SyncClipboard
[ Repository · Jeric-X 5.1k SyncClipboard 跨平台剪贴板同步、历史记录管理工具 / Cross-platform cipboard syncing, history management tool C# ![Jeric-X/SyncClipboard](https://avatars.githubusercontent.com/u/10058586?v=4) ](https://github.com/Jeric-X/SyncClipboard)
![PixPin_2026-06-30_21-06-21.png](https://mio.vlo.cc/mixspace/blog/2026/06/30/3j7p6o3n44l8lixx7v.png)

Windows：小狼毫 Weasel： 目前只能安装SyncClipboard客户端，暂时没找到更好的方法。。。
