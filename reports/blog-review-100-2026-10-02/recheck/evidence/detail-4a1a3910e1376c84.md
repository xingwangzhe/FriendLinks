## 安卓 （云·星穹铁道）
By：牧星长、Rrrrrrray
> 使用 `Via浏览器` 应用商店搜索或下方网盘下载。
> 下载地址
> Via浏览器.apk
> 附件 
> 云·星穹铁道：[**https://sr.mihoyo.com/cloud**](https://sr.mihoyo.com/cloud)
> 视频教程（安卓）
  * 登录进 【云·星穹铁道 】之后，点击 进入游戏，再点击 跃迁 图标进入抽卡界面，再点击底部的 查看详情并点击历史记录。

![srlink-01.webp](https://b.storyo.cn/upload/srlink-01.webp)
  * 等待加载完毕后，点击 地址栏，输入以下代码，点击回车即可。

```
__javascript:(function(){var e=document.querySelector("iframe");if(e){console.log(e.src);prompt("请全选复制以下链接：", e.src);}else{console.error("没有找到抽卡链接，请点击跃迁里的查看详情！");}})();
__
```

  * 回车之后，在页面上就会弹出抽卡链接，全选复制即可

## PC端 （云·星穹铁道）
> 使用`Edge`或`Chrome`浏览器
> 云·星穹铁道：[**https://sr.mihoyo.com/cloud**](https://sr.mihoyo.com/cloud)
  * 登录进 【云·星穹铁道 】之后，点击 进入游戏，再点击 跃迁 图标进入抽卡界面，再点击底部的 查看详情并点击历史记录。

![srlink-01.webp](https://b.storyo.cn/upload/srlink-01.webp)
  * 等待加载完毕后，点击 右上角的3个点的图标，再依次点击 更多工具 -> 开发者工具。

![srlink-03.webp](https://b.storyo.cn/upload/srlink-03.webp)
  * 在开发者工具中，点击 Console （中文名字：控制台） 选项卡，输入以下代码，点击回车再复制链接即可。

```
__javascript:(function(){var e=document.querySelector("iframe");if(!e){alert("没有找到抽卡链接，请点击跃迁/祈愿里的查看详情后再试！");return}var u=e.src;console.log(u);var t=document.createElement("textarea");t.value=u;t.style.position="fixed";t.style.opacity="0";document.body.appendChild(t);t.focus();t.select();try{if(document.execCommand("copy")){alert("抽卡链接已成功复制到剪切板！")}else{prompt("自动复制失败，请全选复制以下链接：",u)}}catch(err){prompt("自动复制失败，请全选复制以下链接：",u)}document.body.removeChild(t)})();__
```

# 👾 PC端（other）
By：星铁小助手、Rrrrrrray

```
__powershell iex(irm ‘https://gitee.com/Rrrrrrray/tools4games/raw/master/StarRail/gachaLink.ps1’)__
```

  * 输入：

