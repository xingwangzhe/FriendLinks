# Extensions & CLI
## Bring Ownable, HugoBlox, and Hugo into your editor and terminal
VS Code
### Ownable for VS Code
Hugo Chat AI + a Contentful-style CMS, right in your editor
Chat with Hugo Chat, manage content through a visual CMS, and ship from your editor — all with your Ownable account signed in.
[Install from Marketplace](https://marketplace.visualstudio.com/items?itemName=ownable.ownable)
npm
### HugoBlox CLI
Scaffold, preview, and deploy HugoBlox sites from your terminal
The official CLI for creating and managing HugoBlox sites. Spin up a new site, sync templates, and ship to the web without leaving your terminal.
[Install from npm](https://www.npmjs.com/package/hugoblox)
VS Code
### Hugo Intellisense
Autocomplete, validation, and docs for Hugo in VS Code
Intellisense and inline documentation for Hugo front matter and shortcodes. Useful for any Hugo project — HugoBlox or not.
[Install from Marketplace](https://marketplace.visualstudio.com/items?itemName=hugoblox.hugo)
