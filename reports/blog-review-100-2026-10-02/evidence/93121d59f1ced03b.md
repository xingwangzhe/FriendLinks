## Questions?
### How is Hugo Chat different from Lovable or v0?
Lovable and v0 generate React apps you throw away in six months. Hugo Chat generates Markdown — plain text files in a git repo you fully own. Same prompt. Sustainable output you can edit forever, in any tool.
### How is Hugo Chat different from ChatGPT for Hugo?
Generic AI is 12–18 months stale on niche frameworks. It invents block names, writes raw HTML, and breaks your build. Hugo Chat is RAG-grounded on the latest HugoBlox docs and block schemas, so what it generates compiles first try.
### Do I have to sign up to try it?
No. Hugo Chat lets you generate sites with no signup. Sign up only when you want to save, deploy, or unlock more chat and Build credits.
### Will I be locked in?
No. The output is plain Markdown in a git repo. If we shut down tomorrow, your site still builds with `hugo` — no Ownable runtime, no proprietary format, no platform tax.
### Can I use my own domain?
Yes. Push the generated Markdown to your own GitHub repo and deploy on GitHub Pages, Netlify, Vercel, Cloudflare Pages — anywhere Hugo runs. Use any domain you own.
### What's the difference between Free and Pro?
Free lets you try Hugo Chat with daily message limits — enough to evaluate. Plus and Pro raise daily limits, add monthly Build credits for full-page generation, unlock the most powerful frontier models, and turn on the editing workflow (CMS Fix-It Bot, GitHub auto-sync, Content Tag Manager).
