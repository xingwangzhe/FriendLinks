A theory _T_ is **simple** if for all sets _B_ and complete types _p_ in _S_ _n_(_B_) there is _A_ ⊆ _B_ such that |_A_ |≤|_T_ | and _p_ does not fork over _A_.  
  
_Alternate Definition:_  
A formula φ(x,y) has the _tree property_ (TP) if there are y-tuples (aη)η∈ω<ω and some k≥2 such that 
  * {φ(x,aσ|n):n<ω} is consistent for all σ∈ωω,
  * {φ(x,aηˆi:i<ω} is  
k-inconsistent for all η∈ω<ω.

A theory is **simple (NTP)** if no formula has the tree property.  
  
See [[105]](https://www.cambridge.org/us/academic/subjects/mathematics/logic-categories-and-sets/course-model-theory), [[106]](https://www.springer.com/gp/book/9780792362210).  
  
_Remarks:_  
One often studies theories in which forking independence is well-behaved. Simple theories have been shown to strongly exemplify this. In particular, the following are equivalent (see [[68]](https://dx.doi.org/10.2307/2695047), [[70]](https://www.sciencedirect.com/science/article/pii/S0168007297000195)): 
  * _T_ is simple.
  * Nonforking (or nondividing) is symmetric.
  * Nonforking (or nondividing) is transitive.
  * Nonforking (or nondividing) has local character.
  * There is a notion of independence (which must be nonforking) satisfying certain properties (see [[68]](https://dx.doi.org/10.2307/2695047)).

Ad hoc terminology:   
Given a formula φ(x,y) and an ordinal α, an **α -tree for φ(x,y)** is a sequence (bη)η∈α<ω of y-tuples such that for all σ∈αω, {φ(x,bσ|n):n<ω} is consistent.  
  
φ(x,y) has the _tree property of the first kind_ (**TP 1**) if there is an ω-tree (bη)η∈ω<ω for φ(x,y) such that for all incomparable η,μ∈ω<ω, {φ(x,bη),φ(x,bμ)} is inconsistent.  
  
φ(x,y) has **SOP 2** if there is a 2-tree (bη)η∈2<ω for φ(x,y) such that for all incomparable η,μ∈2<ω, {φ(x,bη),φ(x,bμ)} is inconsistent.  
  
φ(x,y) has **SOP 1** if there is a 2-tree (bη)η∈2<ω for φ(x,y) such that for all η,μ∈2<ω, if μˆ0⪯η then {φ(x,bη),φ(x,bμˆ1)} is inconsistent.  
  
A theory is **NTP 1** (resp., **NSOP 1**, **NSOP 2**) if no formula has TP1 (resp., SOP1, SOP2).  
  
At the level of theories, NTP1, NSOP1, NSOP2, and NSOP3 are all the same (see the NSOPn+1 region for the definition of SOP3). In particular: 
  * SOP1 ⇒ SOP2 (see [[81]](https://arxiv.org/pdf/2206.08512))
  * SOP2 ⇒ SOP3 (see [[26]](https://arxiv.org/pdf/2608.13291)) 
  * SOP3 ⇒ SOP2 (see [[46]](https://arxiv.org/pdf/math/0009087)). 
  * SOP2 ⇒ SOP1 is clear 
  * TP1 ⇔ SOP2 (see [[46]](https://arxiv.org/pdf/math/0009087), [[69]](https://www.sciencedirect.com/science/article/pii/S0168007211000224)) 

  
_Remarks:_  
In analogy to forking in simple theories, there is a canonical notion of independence in NSOP1 theories called _Kim-forking_. NSOP1 can be characterized by symmetry or transitivity or local character of Kim-nonforking. See [[30]](https://arxiv.org/pdf/1505.00454), [[64]](https://arxiv.org/pdf/1702.03894), [[65]](https://arxiv.org/pdf/1901.07026), [[66]](https://arxiv.org/pdf/1707.02902).  
  
SOP2 is shown to be maximal in Keisler's order in [[73]](https://arxiv.org/pdf/1208.5424), and also characterizes maximality in the ◃∗-order ([[46]](https://arxiv.org/pdf/math/0009087), [[73]](https://arxiv.org/pdf/1208.5424), [[100]](https://www.sciencedirect.com/science/article/pii/S0168007208000250)).

Fix _n_ ≥ 3 and a formula φ(x,y) with |x|=|y|. Then φ(x,y) has the _n-strong order property_ (SOPn) if the set {φ(x1,x2),…,φ(xn−1,xn),φ(xn,x1)} is inconsistent, and there is a sequence (ai)i<ω such that φ(ai,aj) holds for all i<j.  
  
A theory is **NSOP n** if no formula has SOPn.  
  
See [[69]](https://www.sciencedirect.com/science/article/pii/S0168007211000224), [[99]](https://www.sciencedirect.com/science/article/pii/0168007295000666).  
  
The above definition of SOPn works equally well when _n_ is 1 or 2, and in both cases is equivalent to well known properties (of the theory). When _n_ is 1, the condition is equivalent to having an infinite model; and when _n_ is 2, the condition is equivalent to having the order property (instability). However, the acronyms SOP1 and SOP2 are not defined this way in the literature, but rather are used for certain variations of the tree property. See the NTP1/NSOP1,2,3) region for further details.

A type p(x,y), with |x|=|y|, has the _strong order property_ if there are (ai)i∈ω such that p(ai,aj) holds for all i<j, but p(x1,x2)∪…∪p(xn−1,xn)∪p(xn,x1) is unsatisfiable for all n≥2.   
  
A theory is **NFSOP** (no _finitary strong order property_) if no type p(x,y) has the strong order property with |x| finite.   
  
See [[69]](https://www.sciencedirect.com/science/article/pii/S0168007211000224), [[99]](https://www.sciencedirect.com/science/article/pii/0168007295000666).  
  
_Remarks:_  
Two other properties of theories with a close relationship to the finitary strong order property are the _fully finitary strong order property_ and the _strong order property_. The definitions of these properties are obtained by replacing the type in the definition above with, respectively, a formula or a type in arbitrarily many variables. In particular, the strong order property for a theory is equivalent to SOPn for all _n_ ≥ 3.

A formula φ(x,y) has the strict order property (SOP) if there are (ai)i<ω such that ⊨∃x(φ(x,aj)∧¬φ(x,ai))⇔i<j. A theory is **NSOP** if no formula has the strict order property.  
  
See [[69]](https://www.sciencedirect.com/science/article/pii/S0168007211000224), [[99]](https://www.sciencedirect.com/science/article/pii/0168007295000666).  
  
_Remarks:_  
The following characterizations of the strict order property are worth noting. 
  * _T_ has SOP if and only if there is a formula ψ(y1,y2) (with |y1|=|y2|) defining a preorder with infinite chains. (In the above definition, take ψ(y1,y2) to be∀x(φ(x,y1)→φ(x,y2)).)
  * _T_ has SOP if and only if there is a definable set _X_ (in a saturated model) and an automorphism _σ_ such that _σ(X)_ properly contains _X_.

A theory _T_ is **distal** if, for any parameter set _A_ , any _A_ -indiscernible sequence _I_ , and any tuple _b_ , if _I_ = _I 1_ + _I 2_, for some sequences _I 1_ and _I 2_ without endpoints, and _I 1_+_b_ +_I 2_ is indiscernible, then _I 1_+_b_ +_I 2_ is _A_ -indiscernible.   
  
See [[102]](https://arxiv.org/pdf/1103.2239), [[103]](https://www.normalesup.org/~simon/book.html).  
  
_Remarks:_  
The following are two useful characterizations of distal theories. 
  * A theory is distal if and only if it is NIP and all generically stable Keisler measures are smooth.
  * _(Strong honest definitions)_ An NIP theory _T_ is distal if and only if for any formula φ(x,y) there is a formula ψ(x,y1,…,yn), with |yi|=|y|, such that for any finite set _B_ of y-tuples, with |_B_ |≥ 2, and any x-tuple a, there are b1,…,bn in _B_ such that ψ(x,b1,…,bn)⊢tpφ(a/B).

ACF
algebraically closed fields  
  
Axiomatized by the field axioms (in L={+,⋅,0,1}), and the infinite axiom scheme saying every polynomial has a root.  
  
[characterization of forking](https://forkinganddividing.com/ACF.jpg)
The theory can be completed by specifying the characteristic. By quantifier elimination, definable sets (in one variable) are Boolean combinations of polynomial zerosets, and so finite or cofinite.

Q-vector spaces
Axiomatized by the axioms for torsion-free divisible abelian groups in L={+,0}.  
  
[characterization of forking](https://forkinganddividing.com/Qvec.jpg)
By quantifier elimination, definable sets (in one variable) are given as Boolean combinations of formulas of the form _nx = a_ , where _n_ is an integer and _a_ is an arbitrary element. Since the group is torsion free, such sets are finite or cofinite.

bounded pseudo real closed fields
A field _K_ , of characteristic 0, is **bounded** if, for every _n_ , _K_ has only finitely many extensions of degree _n_.  
  
A variety over a field _K_ is **absolutely irreducible** if it is not the union of two algebraic sets over an algebraically closed extension of _K_.  
  
A field _K_ is **pseudo real closed** if, for every absolutely irreducible variety _V_ defined over _K_ , if _V_ has a _K_ r-rational point for every real closure _K_ r of _K_ , then _V_ has a _K_ -rational point. 
We assume here that the pseudo real closed field _K_ is not real closed or algebraically closed, which ensures the independence property, and also that _K_ has at least one order, which ensures the strict order property (a pseudo real closed field with no orders is pseudo algebraically closed).  
  
See [[80]](https://arxiv.org/abs/1411.7654).

See [[85]](https://arxiv.org/pdf/1405.0568) or [[92]](https://www.sciencedirect.com/science/article/pii/S0021869314000751) for the case of one generator, and [[32]](https://arxiv.org/pdf/1704.00105) for the general case.  
  
The failure of dp-minimality can be established using an elementary direct argument similar to Proposition 2.7 of [[41]](https://arxiv.org/pdf/1511.08274). More generally, by [[35]](https://arxiv.org/pdf/1601.05692), there are no proper stable expansions of (Z,+,0) with finite dp-rank. 
extra-special _p_ -group
Given an odd prime _p_ , there is a group _G_ satisfying the following properties: 
  * _G_ is infinite,
  * every nontrivial element of _G_ has order _p_ ,
  * _Z(G)_ is cyclic of order _p_ and equals _G'_.

Such a group _G_ is called an _extra-special p-group_. The defining properties are expressible in the language of groups, and determine a complete theory. 
Supersimple of _SU_ -rank 1, and unstable. Bi-interpretable with the theory of infinite dimensional vector spaces over **F** _p_ with a nondegenerate skew-symmetric bilinear form.  
  
See [[78]](https://hal.archives-ouvertes.fr/hal-00657716v2/document). 
(T,+,⋅,0,1,∂,≤,≼)
ordered valued differential field of logarithmic-exponential transseries  
  
T is a model of the theory _T nl_ of ω-free newtonian Liouville closed _H_ -fields, which is the model companion of the theory of _H_ -fields. The theory _T nl_ has two completions: one with _small derivation_ of which T is a model, and one which does not have small derivation. 
Both completions of _T nl_ are NIP, unstable, and not dp-minimal.  
  
See [[4]](https://arxiv.org/pdf/1509.02588). 
(Z,+,≤p,0,1)
Given a prime _p_ , let ≤p denote the pre-order on integers induced from the _p_ -valuation: _x_ ≤ _y_ if and only if _v p_(_x_)≤ _v p_(_y_). 
  * Dp-minimal, unstable, and not o-minimal.
  * Expanding by the preorders associated to _n_ distinct primes yields dp-rank _n_.
  * Distality fails since the quotient by the equivalence relation defined from the pre-order is stably embedded and has the structure of ℕ with successor. 

See [[2]](https://arxiv.org/pdf/1707.07203). 
(Z,+,0,Sqf)
Complete theory of the abelian group (Z,+,0) expanded by a predicate for the set Sqf of squarefree integers. 
Supersimple of SU-rank 1 and unstable.  
  
See [[13]](https://arxiv.org/pdf/1707.00096). This result builds on [[67]](https://arxiv.org/pdf/1601.07099) which, assuming [Dickson's Conjecture](https://en.wikipedia.org/wiki/Dickson%27s_conjecture), gives the same classification of (Z,+,0,Pr). 
multicolored directed graphs omitting directed cycles

TP2, NSOP and SOP∞.  
  
See [[99]](https://www.sciencedirect.com/science/article/pii/0168007295000666).

generic binary function
The model completion of the empty theory in a language containing only one binary function symbol.  
  
[characterization of forking](https://forkinganddividing.com/genFunction.jpg)
Given a first-order language L, the empty L-theory has a model completion, _T_ 0, whose completions are determined by specifying the diagram of the constant symbols in L. Suppose _T_ is a completion of _T_ 0. Then: 
  * _T_ is NSOP1.
  * If L contains a function symbol of arity at least 2, then _T_ is not simple.
  * If L contains a relation symbol of arity at least 2, then _T_ is unstable.

See [[72]](https://arxiv.org/pdf/1706.06616). 
generic _K m,n_-free bipartite graph
The model completion of the theory of _K m,n_-free bipartite graphs, for _m_ ,_n_ ≥ 2.  
  
[characterization of forking](https://forkinganddividing.com/KmnBP.jpg)
This theory is considered in the language of bipartite graphs consisting of a binary graph relation _I_ , together with unary predicates _P_ and _L_ for the bipartition. Alternatively, one can view _P_ and _L_ as sorts for abstract _points_ and _lines_ , and _I_ as an _incidence_ relation. For example, if _m_ = n = 2, then this is the model completion of the theory of combinatorial projective planes.   
  
See [[34]](https://arxiv.org/pdf/1709.09626). 
Henson digraphs

Constructed to exhibit continuum many pairwise nonisomorphic homogeneous directed graphs.

generic Steiner triple system
The Fraïssé limit of Steiner triple systems in the language of quasigroups. 
A _Steiner triple system_ is a set _X_ together with a collection _B_ of three-element subsets of _X_ (called "blocks"), with the property that any two elements of _X_ lie in a unique block in _B_. If _X_ is a Steiner triple system, then there is a quasigroup operation on _X_ , which sends pairs (_x_ ,_x_) to _x_ , and sends pairs (_x_ ,_y_), with _x_ and _y_ distinct, to the third point on the block determined by _x_ and _y_.   
  
See [[6]](https://arxiv.org/pdf/1805.06767). 
a non-definably-amenable group in a simple theory
Let _K_ be an algebraically closed field of characteristic zero. Then there is a partition 
SL2(_K_) = _C 1_ ∪ _C 2_ ∪ _C 3_ ∪ _C 4_
such that the theory of 
_G_ := (SL2(_K_),⋅,_C 1_,_C 2_,_C 3_,_C 4_)
is supersimple, and for all 1≤ _i_ ≤4, SL2(_K_) can be covered by three left translates of _C i_.  
  
The conditions on the _C i_'s imply that there is no left-invariant finitely additive probability measure on the definable subsets of _G_ , i.e., _G_ is not definably amenable. 
See [[28]](https://arxiv.org/pdf/2105.07281). 
ACF _p_ _G_
Generic expansion of the theory of algebraically closed fields of characteristic _p_ > 0 by an additive subgroup. 
This theory is the model companion of ACF _p_ expanded by a predicate for an additive subgroup.   
  
See [[37]](https://arxiv.org/pdf/1810.11722). 
(C(t),+,⋅,0,1)
The field of rational functions over the complex numbers. 
This field is not superstable, since any infinite superstable field is algebraically closed [[22]](https://www.sciencedirect.com/science/article/pii/0003484380900066). The _stable fields conjecture_ asserts that every infinite stable field is separably closed. C(t) has become a canonical test case for this conjecture.   
  
Other excluded dividing lines: 
  * C(t) is not dp-minimal by the classification of dp-minimal fields (see [[62]](https://arxiv.org/pdf/1507.02745)).
  * C(t) is not supersimple: If _F_ is a supersimple field, then [_F_ ×:(_F_ ×)2] is finite (see Fact 4.2(i) in [[87]](https://arxiv.org/pdf/math/9809189)). In C(t), this index is infinite as witnessed by (t−a)a∈C.
  * C(t) is not distal: A transcendence basis for C over Q is an indiscernible set since any permutation extends to an automorphism of C(t). So distality fails by Example 2.4 in [[102]](https://arxiv.org/pdf/1103.2239). 

  
  
list of open examples
Farey graph
The vertex set of the Farey graph is the projective rational line (i.e., all rational numbers, and a point at infinity identified as 1/0). Two vertices _a_ /_b_ and _c_ /_d_ (in lowest terms) are connected by an edge if and only if |_ad_ - _bc_ | = 1.   
  
[picture of the Farey graph](https://forkinganddividing.com/Farey.png)   
  
[characterization of forking](https://forkinganddividing.com/SFG.jpg)
This graph is planar, and thus ultraflat, which implies it is superstable and dp-minimal. It is not strongly minimal since every vertex has an infinite and co-infinite neighborhood. For ω-stability, see [[39]](https://arxiv.org/pdf/2008.10490) or [[79]](https://arxiv.org/pdf/2503.02121).   
  
See [[56]](http://matwbn.icm.edu.pl/ksiazki/fm/fm118/fm11817.pdf), [[61]](http://matwbn.icm.edu.pl/ksiazki/fm/fm143/fm14322.pdf), [[89]](http://matwbn.icm.edu.pl/ksiazki/fm/fm100/fm100113.pdf). 
Artin braid groups
Given _n_ ≥ 3, the [braid group](https://en.wikipedia.org/wiki/Braid_group) _B_ _n_ is the group with the following presentation  
  
⟨x1,…,xn−1∣xixi+1xi=xi+1xixi+1⟩
  * _B_ _n_ is not supersimple since it interprets a strictly stable group, namely, _B_ 3/_Z_(_B_ 3). The latter group is isomorphic to _C_ 2∗ _C_ 3, which is stable [[95]](https://arxiv.org/pdf/1012.0044) and not superstable [[83]](https://arxiv.org/pdf/0809.3441), [[90]](https://doi.org/10.2307/2273551). See also [[17]](https://arxiv.org/pdf/2507.21575) and this [MathOverflow post](https://mathoverflow.net/questions/239697/are-braid-groups-with-finitely-many-generators-nip/515320#515320).
  * _B_ _n_ contains the free group on 2 generators as a subgroup, and thus is not dp-minimal by Proposition 3.1 in [[101]](https://arxiv.org/pdf/0909.4242).
  * If _m_ ≠ _n_ then _B_ _m_ and _B_ _n_ are not elementarily equivalent [[63]](https://arxiv.org/pdf/1707.08353). Thus this entry is really a family of theories with potentially distinct properties.

  
  
list of open examples
a strictly stable expansion of (Z,+,0)
Let Q be the set of factorials and let Q be an arbitrary structure with universe Q. Consider the expansion (Z,+,0,Q) of (Z,+,0) obtained by naming Q with a unary predicate and enriching it with the structure Q. Then (Z,+,0,Q) is strictly stable if and only if Q is. (The same holds for superstable, NIP, NTP2, simple, and NSOP1.)  
  
See [[33]](https://arxiv.org/pdf/2203.07226). 
One can accomplish this with an expansion by a single unary predicate as follows. Suppose Q is a graph (Q,E). Define A=Q∪{x+y:(x,y)∈E}. Then (Z,+,0,A) is interdefinable with (Z,+,Q). For a strictly stable example, let Q be a countable model of the graph defined here. Or one can construct a graph bi-interpretable with any given structure in a finite language (see Theorem 5.5.1 in [[58]](https://www.cambridge.org/core/books/model-theory/BB219FC37218A7CADE5906625E6B4BC1)).   
  
The failure of dp-minimality (which happens even in the reduct (Z,+,0,Q)) can be established using an elementary direct argument similar to Proposition 2.7 of [[41]](https://arxiv.org/pdf/1511.08274). More generally, by [[35]](https://arxiv.org/pdf/1601.05692), there are no proper stable expansions of (Z,+,0) with finite dp-rank. 
finitely many infinitely cross-cutting equivalence relations
Finitely many equivalence relations _E_ 1,…,_E_ n (with _n_ ≥ 2) such that each _E_ i has infinitely many infinite classes, and for all distinct _i_ ,_j_ ≤ _n_ , every _E_ _i_ -class intersects every _E_ _j_ -class in an infinite set. 
See [[5]](https://projecteuclid.org/euclid.pl/1235414194). 
infinitely expanding equivalence relations
Equivalence relations _E_ i, indexed by some fixed ordinal α, such that _E_ 0 is equality and for any _i_ < _j_ < α, each _E_ _j_ -class is partitioned into infinitely many _E_ _i_ _-classes._
_
This example is similar to others on the map taken from [[5]](https://projecteuclid.org/euclid.pl/1235414194). With the ordinal α fixed, the theory is complete with quantifier elimination, and has _U_ -rank α. 
generic 2-nilpotent group of exponent _p_ > 2
Fraïssé limit of finite 2-nilpotent groups of exponent _p_ > 2 (where _p_ is a fixed prime). 
The Fraïssé class is defined in the language of groups with a unary predicate _P_. The elements of the class are finite 2-nilpotent groups of exponent _p_ and with _P_ naming a normal subgroup lying between derived subgroup and the center. In the Fraïssé limit, _P_ is the center (and the derived subgroup) hence is definable in the group language. The analogue of this example for higher nilpotency class is described here.  
  
See [[8]](https://londmathsoc.onlinelibrary.wiley.com/doi/abs/10.1112/S002460930100827X), [[10]](https://arxiv.org/pdf/1406.2964), [[38]](https://arxiv.org/pdf/2310.17595). 
generic _c_ -nilpotent group of exponent _p_ > _c_ > 2
Fraïssé limit of finite _c_ -nilpotent groups of exponent _p_ > _c_ > 2 (where _p_ is a fixed prime and _c_ is a fixed integer). 
The Fraïssé class is defined in the language of groups with _c_ -1 additional unary predicates naming a Lazard series. In the Fraïssé limit, these predicates coincide with the upper and lower central series, and are definable in the group language. The analogue of this example for 2-nilpotent groups is described here.  
  
See [[9]](https://londmathsoc.onlinelibrary.wiley.com/doi/abs/10.1112/S002460930400339X), [[38]](https://arxiv.org/pdf/2310.17595).

a non-ω-stable tree
Define the (graph-theoretic) tree _G_ whose vertex set is the union of: 
  * {w}
  * {xσ,i:σ∈2<ω,i<|σ|}
  * {yσ,i:σ∈2<ω,i<|σ|,σ(i)=1},

and with the following edges: 
  * for each σ∈2<ω, the path (w,xσ,0,…,xσ,|σ|−1)
  * for each σ∈2<ω and i<σ with σ(i)=1, an edge between xσ,i and yσ,i.

Superstability holds more generally for the theory of any planar (or even ultraflat) graph [[56]](http://matwbn.icm.edu.pl/ksiazki/fm/fm118/fm11817.pdf). This construction is similar to the non-ω-stable planar lattice given in Example 3.5 of [[104]](https://www.cambridge.org/core/services/aop-cambridge-core/content/view/AD8F1CF862C200B63125F4A0A0EA8586/S0008414X00034854a.pdf/stability-and-categoricity-of-lattices.pdf).

a supersimple theory without stable forking
The two-sorted theory of an infinite-dimensional module over the division ring of fractions of the quantum algebra _R_ of the random bipartite graph Γ.  
  
Here _R_ is the Q-algebra Q[{Xi}i∈Γ] where XiXj=XjXi if _i,j_ are in the same part of Γ or connected in Γ, and otherwise XiXj=−XjXi.   
  
Sorts are included for Γ with the partition and edge relation, and for the module _V_ with scalar multiplication by the Γ-labeled generators of _R_.
