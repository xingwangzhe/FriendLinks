# 复活一下老项目 PanIndex
by [KasuganoSora](https://lo-li.cn/author/kasuganosora) [ 发表评论](https://lo-li.cn/1926#respond)
PanIndex 是一个很好用的网盘列表程序，我之前一直都在用，但是后来天翼云接口失效后就没用了，最近偶然需要用到天翼云，干脆就顺手 Vibe coding 一下，把这个项目复活了。
![image](https://i.zerodream.net/592d4297e8a91aaf1e64cfd20c67be46.png)
很惭愧，就是做了一点微小的工作：
  * 使用 TailwindCSS + Vue 重构了管理员后台
  * 新增了下载统计页面，实时查看最新数据
  * 新增了 Oxygen 主题，也是用 TailwindCSS 和 Vue 构建的
  * 新增了 README.md 和 HEAD.md 文件显示和隐藏功能
  * 修复了天翼云登录接口，现在改用 PC 接口（原本是网页端）
  * 对界面进行了一些个人喜好的小改造
  * 将老旧的 Markdown 解析库升级为更现代、仍在维护的 Markdown-it 解析库
