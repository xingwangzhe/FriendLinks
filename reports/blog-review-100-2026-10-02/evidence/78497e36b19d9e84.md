# An open source tool for building Design Systems with [Vue.js](https://vuejs.org)
Vue Design System provides you and your team a set of organized tools, patterns & practices. It works as the foundation for your application development. 
[Download _(v3.5.7)_](https://github.com/arielsalminen/vue-design-system) [Docs](https://github.com/arielsalminen/vue-design-system/wiki)
[ View example documentation ](https://vueds.com/example/)
## Features
### [Built for Your Team A set of interconnected patterns & practices for you and your team with comprehensive documentation. ](https://github.com/arielsalminen/vue-design-system) ### [Naming of Things A well thought-out terminology, naming conventions, and hierarchy for the whole design system to save time. ](https://github.com/arielsalminen/vue-design-system/wiki/Naming-of-Things) ### [Component Status WIP Get an automated overview of how your design system progresses over time and what’s still left to do. ](https://github.com/arielsalminen/vue-design-system/wiki/Component-Status) ### [Design Tokens Global design tokens in YAML format that you can use inside any component. In both CSS and JavaScript. ](https://github.com/arielsalminen/vue-design-system/wiki/Working-with-the-System) ### [Living Docs Automatic generation of living, user editable documentation using custom version of Vue Styleguidist. ](https://github.com/arielsalminen/vue-design-system/wiki/Editing-Living-Documentation) ### [Publish via NPM Easily export and use your Design System as an NPM dependency in another Vue.js project (or anywhere really). ](https://github.com/arielsalminen/vue-design-system/wiki/Getting-Started) ### [Faster Workflow Create a token, an element, or a pattern, and it’s immediately available across all your Vue.js components. ](https://github.com/arielsalminen/vue-design-system/wiki/terminology) ### [Code Formatting Pre-configured Prettier setup for auto-formatting code on both save and before committing changes to Git. ](https://github.com/arielsalminen/vue-design-system/blob/master/.prettierrc) ### [Configurable Live Reloading, Autoprefixing, SCSS and helper functions + good defaults for SVG and Webfont usage out-of-the-box. ](https://github.com/arielsalminen/vue-design-system/wiki/Frequently-Asked-Questions-\(FAQ\))
