# 3D 节点标签系统

> 2026-11-14 按当前源码同步。运行环境使用 Bun；浏览器渲染使用 Three.js r187。

## 实现与入口

标签使用 Canvas 2D 绘制文字，再生成 `THREE.CanvasTexture` 和 `THREE.Sprite`。字体为浏览器系统 `sans-serif`，不依赖外部字体 CDN 或文字渲染包。

- `src/scripts/graph3d/utils.ts`：`createTextSprite(text, worldHeight = 5, fontSize = 48)` 创建标签。
- `src/scripts/graph3d/index.ts`：`ensureLabels()` 按当前视锥、相机距离和画质预算选择普通标签；`removeLabel()` 释放被淘汰的标签。
- `src/scripts/graph3d/render-scheduler.ts`：合并绘制请求，相机与标签都稳定后停止申请下一帧。
- `buildNeighborLabels()` 创建聚焦节点及其邻居的标签，`clearNeighborLabels()` 释放这些标签。

## 普通标签

`LabelCandidateIndex` 在固定布局上建立 600 世界单位的空间格；`ensureLabels()` 查询附近单元。标签开关关闭或存在聚焦节点时不创建普通标签，避免与聚焦标签重叠。尚无坐标的节点跳过；名称使用 `name || id`，长度超过 40 的名称不生成标签。

候选必须处于当前相机视锥内。新标签的创建距离为 600 世界单位，已创建标签可以保留到 1500 世界单位；使用有界最大堆只保留画质预算内最近的候选，同距离按原节点索引排序；保留半径内的旧标签单独补充且不重复计数。离开视锥、超出保留距离或超出预算的标签会被移除，释放纹理和材质，并清除 `labelsCreated` 中的节点索引。因此转向后，画面外的旧标签不会继续占满预算。

普通标签世界高度为 12，Canvas 字号为 48px，位置为节点上方 `nodeSize + 8`。透明度在 `LABEL_FADE_FULL = 1000` 到 `LABEL_MAX_FADE_START = 3000` 之间随距离变化；扫描还会按上述保留距离淘汰资源。标签所在组为 `labels`。

## 画质预算与调度

控制面板默认选择节能画质。画质选择保存在 `friendlinks_render_quality`，下次访问时恢复。

| 画质            | 手动跟随画质时上限 | 普通标签预算 | 邻居标签上限 | DPR 上限 |
| --------------- | ------------------ | ------------ | ------------ | -------- |
| 节能 `low`      | 30 FPS             | 48           | 40           | 1        |
| 均衡 `balanced` | 45 FPS             | 96           | 100          | 1.5      |
| 清晰 `high`     | 60 FPS             | 160          | 300          | 2        |

实际 DPR 取设备 DPR 与档位上限的较小值。邻居标签还受控制面板的连线数上限限制；聚焦节点自己的标签在邻居上限之外另计一个。

独立的「帧率上限」默认「无限制」，取消应用节流并跟随浏览器 RAF：60 Hz 屏幕通常约 60 FPS，高刷新率设备可超过 60。手动选择「跟随画质」才使用表中上限。该选择保存为 `friendlinks_unlimited_fps`，切换画质仍保留，不改变标签预算和 DPR；静止及后台均停绘。

相机位置、相机朝向、标签开关、画质或视口尺寸变化会标记标签需要更新，并请求绘制。需要更新时，空间候选查询至少间隔 150ms，每次最多生成 4 张新文字纹理；仍有待创建标签时由一个可取消的延迟任务唤醒下一批，等待期间不重复绘制 GPU 帧，直到候选补齐。每个实际绘制帧会更新现有标签的显隐和透明度，确保取消聚焦或重新显示标签后恢复正确。

相机和标签稳定后不再扫描节点，也不再重复绘制。页面隐藏时暂停调度，恢复可见时重新检查标签。FPS 文本在活动期间显示测得的绘制频率，静止时显示 `空闲停绘`；画质中的 FPS 是上限，不代表设备一定达到该帧率。

## 聚焦标签

`buildNeighborLabels()` 从邻居映射中读取节点，通过节点 ID 索引查找数据，创建 `neighborLabels` 组。聚焦节点使用 44px Canvas 字号，邻居使用 36px；名称长度同样限制为 40。

实际绘制时根据相机朝向将标签放在节点上方，并按视口高度与距离换算世界尺寸，保持接近固定的屏幕字号。聚焦节点目标高度为 24px，邻居目标高度随标签数量降低，最低 12px。画质或连线数上限变化会重建当前聚焦标签。

## 材质与资源释放

Sprite 材质开启透明，关闭 `depthTest` 和 `depthWrite`，`renderOrder` 为 999。纹理使用线性过滤，Sprite 宽高比由 Canvas 尺寸决定；Sprite 自动面向相机。

普通标签淘汰、清除邻居标签以及图实例 `dispose()` 时都会释放对应纹理和材质。重复初始化图实例与开发热更新会清理旧实例，避免旧标签和绘制调度残留。页面隐藏和销毁时会取消待执行的标签任务；没有持续的标签轮询计时器。

## 控制与排查

控制面板的标签开关通过 `friendlinks_label_show` 持久化。重新开启会标记标签更新并唤醒绘制；聚焦状态下普通标签组隐藏，显示聚焦标签。

| 现象                  | 检查方向                                                         |
| --------------------- | ---------------------------------------------------------------- |
| 普通标签不显示        | 检查开关、聚焦状态、坐标、视锥、创建距离、名称长度和当前画质预算 |
| 转向或远离后标签消失  | 视锥选择、距离淡出和预算淘汰属于正常行为                         |
| 刚靠近时标签分批出现  | 每次最多生成 4 张文字纹理，避免集中创建阻塞主线程                |
| 中文字形缺失          | 检查系统字体是否包含对应字符及浏览器字体回退                     |
| 聚焦后普通标签隐藏    | 普通标签与聚焦标签分别管理，避免重叠                             |
| 静止时 FPS 文字不跳动 | 显示 `空闲停绘` 代表调度器已停止连续绘制                         |

性能计数与复核方法见 [前端性能验证](PERFORMANCE.md)。

## 历史方案

早期尝试过 `troika-three-text` 和 `@seregpie/three.text-sprite`，分别遇到字体 CDN 依赖和异步字体加载问题。当前自实现 Canvas Sprite 已替代这些方案；历史 `Graph.graphData()`、`createLabels()`、`pruneLabels()` 和定时全节点扫描示例不再作为当前实现指南。
